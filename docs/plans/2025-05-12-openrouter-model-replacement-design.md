# OpenRouter 模型替换脚本设计

**日期**: 2025-05-12  
**主题**: 自动从 OpenRouter 获取可用模型并替换 AI-Models.txt 中的 openroute 模型  
**状态**: 已批准

## 背景

项目中使用 `AI-Models.txt` 管理各提供商的 AI 模型列表，其中包含 `openroute/` 前缀的模型。需要定期从 `openrouter_models.txt` 获取最新模型，检测其可用性，并自动替换 `AI-Models.txt` 中的 openroute 模型。

## 需求

1. 从 `openrouter_models.txt` 读取候选模型列表（用户已将其格式化为与 AI-Models.txt 一致的格式）
2. 使用 `check-models.sh` 的检测逻辑验证模型可用性
3. 用可用模型替换 `AI-Models.txt` 中所有 `openroute/` 开头的模型行
4. 保留文件中的注释、空行和其他提供商的模型

## 设计方案

### 脚本名称

`update-openroute-models.sh`

### 核心流程

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 读取候选模型                                              │
│    - 从 openrouter_models.txt 读取所有非注释、非空行          │
│    - 每行格式应为: openroute/模型ID                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 检测可用性                                                │
│    - 生成临时模型列表文件                                    │
│    - 调用 check-models.sh 进行检测                           │
│    - 解析输出，提取状态为 OK 的模型                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 替换目标文件                                              │
│    - 读取 AI-Models.txt                                      │
│    - 移除所有 openroute/ 开头的行                            │
│    - 在原位置插入检测到的可用模型                             │
└─────────────────────────────────────────────────────────────┘
```

### 边界处理

| 场景 | 处理方式 |
|------|---------|
| 无可用模型 | 输出警告，不修改目标文件 |
| 目标文件无 openroute 行 | 在文件末尾追加可用模型 |
| 源文件为空或无候选模型 | 输出提示，正常退出 |

### 使用方式

```bash
./update-openroute-models.sh [源文件] [目标文件]

# 示例
./update-openroute-models.sh openrouter_models.txt AI-Models.txt
```

## 技术细节

### 检测逻辑复用

脚本通过调用现有的 `check-models.sh` 来检测模型可用性，而非内嵌检测逻辑。这确保了：
- 检测行为与现有工具完全一致
- 环境变量、API Key 等配置自动继承
- 当 check-models.sh 更新时，替换脚本无需修改

### 输出解析

`check-models.sh` 的输出格式为 `状态|模型名|详情`，例如：
- `OK|openroute/model|123ms`
- `FAIL|openroute/model|HTTP 404`

脚本通过正则匹配提取状态为 `OK` 的模型。
